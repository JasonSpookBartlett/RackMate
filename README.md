# RackMate V1 Beta

Ready for GitHub Pages.

Upload these files to the root of a GitHub repository:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Then enable GitHub Pages from Settings > Pages, publishing from the main branch and root folder.
On Android, open the Pages URL in Chrome and choose Install app or Add to Home screen.
